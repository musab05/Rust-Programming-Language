## 1. What Are Procedural Macros?

Procedural macros operate on Rust **token streams** — they receive code as input and produce code as output:

```
Input TokenStream  →  [Your Rust Code]  →  Output TokenStream
     (source)          (proc macro fn)        (generated code)
```

Unlike `macro_rules!` (pattern matching), proc macros can run arbitrary Rust code at compile time.

---

## 2. Three Types of Proc Macros

| Type | Syntax | Purpose |
|---|---|---|
| **Derive** | `#[derive(MyMacro)]` | Auto-implement traits |
| **Attribute** | `#[my_macro]` | Transform items (functions, structs) |
| **Function-like** | `my_macro!(...)` | Arbitrary token transformation |

```rust
// Derive — generates trait implementation
#[derive(Debug, Clone, Serialize)]
struct User { name: String }

// Attribute — transforms the item
#[route(GET, "/users")]
async fn get_users() { }

// Function-like — generates arbitrary code
html! { <div class="hello">Hi</div> }
```

## 3. Derive Macros

The most common type — you use them every day:

```rust
// Standard derive macros
#[derive(Debug)]          // auto-implements Debug
#[derive(Clone)]          // auto-implements Clone
#[derive(PartialEq, Eq)]  // auto-implements equality
#[derive(Hash)]           // auto-implements Hash
#[derive(Default)]        // auto-implements Default
struct Point {
    x: f64,
    y: f64,
}

fn main() {
    let p = Point { x: 1.0, y: 2.0 };
    let p2 = p.clone();
    println!("{:?}", p);
    println!("Equal: {}", p == p2);
}
```

### Popular third-party derives:

```rust
use serde::{Serialize, Deserialize};

#[derive(Debug, Serialize, Deserialize)]
struct Config {
    host: String,
    port: u16,
    debug: bool,
}

fn main() {
    let config = Config {
        host: "localhost".into(),
        port: 8080,
        debug: true,
    };

    // Serialize to JSON (generated by derive macro!)
    let json = serde_json::to_string_pretty(&config).unwrap();
    println!("{json}");

    // Deserialize from JSON
    let parsed: Config = serde_json::from_str(&json).unwrap();
    println!("{:?}", parsed);
}
```

## 4. Building a Custom Derive

### Project structure:

```
my_derive/
├── Cargo.toml          ← proc-macro crate
└── src/
    └── lib.rs

my_app/
├── Cargo.toml          ← application
└── src/
    └── main.rs
```

### The proc-macro crate (`my_derive/Cargo.toml`):

```toml
[package]
name = "my_derive"
version = "0.1.0"
edition = "2021"

[lib]
proc-macro = true       # ← marks this as a proc-macro crate

[dependencies]
syn = { version = "2", features = ["full"] }
quote = "1"
proc-macro2 = "1"
```

### The derive macro (`my_derive/src/lib.rs`):

```rust
use proc_macro::TokenStream;
use quote::quote;
use syn::{parse_macro_input, DeriveInput};

/// Generates a `describe()` method for the struct.
#[proc_macro_derive(Describe)]
pub fn describe_derive(input: TokenStream) -> TokenStream {
    let input = parse_macro_input!(input as DeriveInput);
    let name = &input.ident;  // struct name

    let expanded = quote! {
        impl #name {
            pub fn describe(&self) -> String {
                format!("This is a {} struct", stringify!(#name))
            }
        }
    };

    TokenStream::from(expanded)
}
```

### Using the derive (`my_app/src/main.rs`):

```rust
use my_derive::Describe;

#[derive(Describe)]
struct User {
    name: String,
    age: u32,
}

fn main() {
    let user = User { name: "Alice".into(), age: 30 };
    println!("{}", user.describe());  // "This is a User struct"
}
```

## 5. Attribute Macros

Transform entire items:

```rust
// Definition (in proc-macro crate):
#[proc_macro_attribute]
pub fn log_call(attr: TokenStream, item: TokenStream) -> TokenStream {
    let input = parse_macro_input!(item as syn::ItemFn);
    let name = &input.sig.ident;
    let block = &input.block;
    let sig = &input.sig;

    let expanded = quote! {
        #sig {
            println!("→ Calling {}", stringify!(#name));
            let result = { #block };
            println!("← {} returned", stringify!(#name));
            result
        }
    };

    TokenStream::from(expanded)
}

// Usage:
#[log_call]
fn add(a: i32, b: i32) -> i32 {
    a + b
}
// Calling add(3, 4) prints:
// → Calling add
// ← add returned
```

### Web framework attributes:

```rust
// Actix-web example (how it works behind the scenes)
#[get("/users/{id}")]
async fn get_user(id: web::Path<u32>) -> impl Responder {
    format!("User {}", id)
}

// Tokio test macro
#[tokio::test]
async fn test_async() {
    assert_eq!(2 + 2, 4);
}
```

## 6. Function-Like Proc Macros

Look like function calls but operate on tokens:

```rust
// Definition:
#[proc_macro]
pub fn make_struct(input: TokenStream) -> TokenStream {
    // Parse and transform the input tokens
    // Return generated code
    todo!()
}

// Usage:
make_struct!(User { name: String, age: u32 });
```

### Real-world examples:

```rust
// sqlx — compile-time verified SQL
let users = sqlx::query!("SELECT id, name FROM users WHERE age > $1", 18)
    .fetch_all(&pool)
    .await?;

// html! macro in Yew
html! {
    <div class="container">
        <h1>{ "Hello World" }</h1>
    </div>
}
```

## 7. The syn and quote Crates

### syn — Parse Rust code into a syntax tree:

```rust
use syn::{parse_macro_input, DeriveInput, Data, Fields};

fn process(input: DeriveInput) {
    let name = input.ident;  // struct/enum name

    match input.data {
        Data::Struct(data) => {
            match data.fields {
                Fields::Named(fields) => {
                    for field in fields.named {
                        let field_name = field.ident.unwrap();
                        let field_type = field.ty;
                        // process each field...
                    }
                }
                _ => {}
            }
        }
        Data::Enum(data) => {
            for variant in data.variants {
                let variant_name = variant.ident;
                // process each variant...
            }
        }
        _ => {}
    }
}
```

### quote — Generate Rust code from templates:

```rust
use quote::quote;

let name = syn::Ident::new("MyStruct", proc_macro2::Span::call_site());
let field_count = 3;

let tokens = quote! {
    impl #name {
        pub fn field_count() -> usize { #field_count }
        pub fn type_name() -> &'static str { stringify!(#name) }
    }
};
// Generates valid Rust code as a TokenStream
```

## 8. Popular Derive Macros

| Crate | Derive | Purpose |
|---|---|---|
| std | `Debug, Clone, Copy, PartialEq, Eq, Hash, Default` | Standard traits |
| serde | `Serialize, Deserialize` | JSON/YAML/TOML serialization |
| clap | `Parser` | CLI argument parsing |
| thiserror | `Error` | Custom error types |
| strum | `EnumString, Display` | Enum utilities |
| sqlx | `FromRow` | Database row mapping |

```rust
// thiserror — generates Display + Error impl
use thiserror::Error;

#[derive(Error, Debug)]
enum AppError {
    #[error("Not found: {0}")]
    NotFound(String),
    #[error("Database error")]
    Database(#[from] sqlx::Error),
}

// clap — generates CLI parser
use clap::Parser;

#[derive(Parser)]
struct Cli {
    #[arg(short, long)]
    name: String,
    #[arg(short, long, default_value_t = 8080)]
    port: u16,
}
```

## 9. When to Use Which Macro Type

```
Need to ...                          → Use
────────────────────────────────────────────────────
Reduce boilerplate in THIS file      → macro_rules!
Auto-implement a trait for structs   → Derive macro
Transform a function/struct          → Attribute macro
Custom DSL syntax                    → Function-like proc macro
Simple pattern-based expansion       → macro_rules!
Complex code generation              → Proc macro
```

## 10. Summary Cheat Sheet

```
THREE PROC MACRO TYPES
────────────────────────────────────────────────────────────
#[derive(MyMacro)]       auto-implement traits
#[my_attr]               transform items
my_macro!(...)           function-like

PROC MACRO CRATE SETUP
────────────────────────────────────────────────────────────
[lib]
proc-macro = true

[dependencies]
syn = "2"
quote = "1"

KEY CRATES
────────────────────────────────────────────────────────────
syn       parse TokenStream into AST
quote     generate TokenStream from templates
proc-macro2  proc-macro types for libraries

DERIVE MACRO SKELETON
────────────────────────────────────────────────────────────
#[proc_macro_derive(Name)]
pub fn name_derive(input: TokenStream) -> TokenStream {
    let input = parse_macro_input!(input as DeriveInput);
    let name = &input.ident;
    let expanded = quote! { impl #name { ... } };
    TokenStream::from(expanded)
}

POPULAR DERIVES
────────────────────────────────────────────────────────────
Debug, Clone, Serialize, Deserialize
Parser (clap), Error (thiserror), FromRow (sqlx)
```
